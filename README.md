# Кубик

[Открыть математическую мастерскую](https://blog.theivan.io/kubik-math/)

Домашняя математика через строительство для детей пяти лет. В первых 12 неделях есть 36 готовых занятий и 12 необязательных проектов. На месяцы 4–12 даны планы по неделям. Взрослый выбирает игры в удобном темпе.

## Как добавить наблюдение

После занятия можно прислать в чат название или код урока, дату и несколько слов о том, как всё прошло. Форма под уроком готовит такой текст. Черновик хранится в текущей вкладке браузера.

По просьбе семьи добавьте запись в массив `src/content/journal.json`, сохранив предыдущие. Пример формата приведён ниже. В опубликованном журнале запись и указанные в ней сведения становятся общедоступными.

```json
{
  "lessonId": "01-a",
  "date": "2026-11-21",
  "outcome": "с подсказкой",
  "observation": "Собрал шесть деталей, перекладывая их по одной.",
  "next": "Попробовать такой же заказ с ложками."
}
```

У каждой недели три кода занятий с окончаниями `a`, `b`, `c`. Номер недели пишется двумя цифрами. Статусы — `сам`, `с подсказкой`, `пока трудно`, `не пробовали`. Поле `next` необязательно. Каждый проведённый урок учитывается в прогрессе один раз, даже когда у него несколько записей. Статус «не пробовали» оставляет урок доступным как ближайший.

## Разработка и публикация

Проект использует React, TypeScript, TanStack Router, pnpm и Vite+. Для локальной разработки нужен Node.js 22.18 или новее из ветки 22, либо совместимая версия из package.json.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Команда `pnpm build` проверяет типы, структуру курса и записи журнала, затем собирает сайт в `dist/`. После отправки изменений в `main` GitHub Actions публикует сборку на GitHub Pages. Адреса с фрагментом позволяют открывать отдельные уроки напрямую.
